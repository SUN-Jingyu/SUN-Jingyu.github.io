# 本文档记录26求职笔试的一些问题以及总结

## 公司背调

1. 这个公司目前的业务和主要业务、核心市场
2. 目前这家公司的竞争对手，包含国内国外
3. 这个行业的发展趋势
4. 公司财报里关注下营收、利润、以及未来的规划
5. 这个岗位的要求，JD
6. 海外出差的频率还有报销形式、是否有补贴

## 面试准备环节

### 海外解决方工程师/售前工程师理解

1. 为什么选择该岗位：
    我认为解决方案工程师是连接客户需求与技术实现之间的桥梁，不仅要懂产品、更要懂客户。这个角色既要具备技术能力，能理解公司产品（如光伏/储能系统）的架构与实现；也要具备沟通与场景抽象能力，能深入理解客户业务场景、制定合理可行的系统解决方案，并推动其落地交付。   
2. 怎样做好客户关系
    - 专业素养：技术能力，逻辑思维，行业认知
    - 职业能力：形象，责任，稳重，抗压，声誉维护
    - 商业意识：客户理解、市场洞察，主动参加行业交流活动

## 🙋 面试反问

1. 您希望个人对该岗位有什么样的能力要求
2. 该岗位目前的核心考核指标是什么，进来需要解决什么问题？
3. 现在部门有多少人，怎么样分工的，工作风格怎样的。
4. 您对我有什么建议。

## 💰 谈薪  

1. 薪资结构
    1. 通用
        1. 提成怎么计算？是按照签单金额还是销售利润来计算？
        2. 补贴是指那些？
        3. 有年终奖么？年终奖会写进合同么？是按季度发放还是年终？
        4. 每月几号发工资
        5. 试用期多久？试用期工资？
        6. 五险一金缴纳比例？
        7. 劳动合同按照实际工资签订么？以上内容会写到劳动合同里么？
    2. 海外出差
        1. 出差补贴
        2. 出差住宿交通价位  

2. 先发制人  

    从个人学习能力上，以及英语表达能力上完全可以胜任该岗位，并且我了解到公司在AI业务上再进一步发展，我有过AI的学习经历，代表公司给到客户带来足够的信心。  

3. 合理让步  

    如果我的期望薪资和公司所能给的薪资有差距，可以适当调整。和初始薪资相比，我更看重成长性，而且公司的平台和发展机会是符合我的职业预期，相信公司会有合理的薪资安排。
