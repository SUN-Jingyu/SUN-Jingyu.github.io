# 本文档记录26求职笔试的一些问题以及总结

## 面试反问

### 主管面试

    1. 您希望个人对该岗位有什么样的能力要求
    2. 该岗位目前的核心考核指标是什么，进来需要解决什么问题？
    3. 现在部门有多少人，怎么样分工的，工作风格怎样的。
    4. 您对我有什么建议。
