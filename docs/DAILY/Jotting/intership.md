# HQ实习感悟  

> 本文主要记录了个人在HQ实习的三个月的一些所感所悟，从9.1号入职到12.1号离职。 11.30.2025

## 序言

该实习的offer是我2025年英国留学期间大概六月份所收到的，那段时间也是在为毕设和秋招做准备，当时的一个心态还是主要寻找全职offer并不是实习岗位，全职的岗位主要是有关硬件工程师的岗位或者集成电路IC设计或者FAE的岗位，机缘巧合下通过某BS平台了解到BSP的岗位以及公司，并拿下了offer，算是自此开启人生的新篇章吧。

## 职场

第一次见到公司的大楼就让我耳目一新，没想到公司是如此的大气，整体上符合我对大厂的刻板印象，其实来之前有了解过公司的员工文化，加班很严重，但是当时就觉得也无所谓，因为上学时候自己给自己的压力也很大。同事，导师以及领导都很好也很照顾我。

随着在公司呆的时间增长，参加公司的各类活动，无论是夜跑还是各类协会，结识到了很多志同道合的朋友。这些朋友也为后期转行不再从事研发岗带来了一定的思考。

偶然翻看公司的文化遗迹老板的演讲，对公司的价值观十分认可，**“看三到五年的事，做正确的事，做有挑战的事”**，这句话是令我记忆最深刻的，和大道先生的观念偶然的相似性。整体来说公司的文化个人而言还是符合一个上市公司的标准的，目前的市值个人觉得还是低于其本身的价值的，但是相比于Costco以及Insta360我所了解的企业文化，还是有学习的地方。但是这句话也是影响我很深也为我带来了一些职业的思考。就比如未来三到五年我是否还会坚持做研发？

这三个月很多的时间还是在秋招做准备，每天除了投递简历外，就是面试，或者协助导师以及师兄去完成Bug的修复以及功能的开发实现。

不得不说我在我师兄身上也学习到了很多，对待问题的专注度以及解决问题的能力都是我值得学习的，举个例子，对于公司代码的下载可能需要二到三个小时，经过他的检索以及尝试，选用了分段下载的方式依赖于Motrix平台来最终提高了代码的网络下载速度，大大的缩短了开发时间，如果换作是我，我就觉得代码下载慢是公司的问题，不是我的问题，我也不会想到什么解决方式，他的这个行为以及对待工作的态度也为后期职业发展带来了一些思考。

除了师兄就是我的导师虽然他们都是i人，但是我的导师是究极i人，导师从事这个行业也是十多年了，很刻板的程序员印象。对我导师的印象就是每天上班和下班时间都能看到导师在工位上思考，说实话我们部门的压力还是很大的。对我导师印象最深的就是他所做的 **PPT**，不愧是晋级答辩第一的选手，对于问题的分析以及图文表达能力真的令我感到震撼，一个小小的软件bug就能从硬件晶振的源头开始分析乃至使用示波器等仪器，并且将 **问题的分析流程以及思考内容都以流程图的形式呈现**，这一点让我学习到了作为一个模块的负责人应有的样子，并且也让我对工作的态度以及职业的发展带来了一些思考。

## 感悟

三个月的实习时间很快，看到有些文章说 *“实习生最应该做的不是在这实习期间快速学习新技能或者掌握业务能力，而是通过这个平台以及社会的属性了解这个行业以及岗位是否是自己未来想要持续的做下去的”*，我总是拿这句话来安慰自己、欺骗自己，因为说实话我并没有觉得我这三个月有任何的专业能力的提高，但是这三个月对我的来说最大的收获是我模糊的知道我未来想要成为什么样的人，想要做什么样的事，我觉得这三个月的时间花在这里是值得的不后悔的。因为我起码以极低的成本或者说是0成本去排除了一项我知道我不会做的，**避免了犯错**，写到这里让我想起来查理先生以及大道先生所说的，大概意思就是 **不去做错误的事就是最正确的选择**
